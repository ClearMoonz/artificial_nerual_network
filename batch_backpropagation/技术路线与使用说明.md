# 第85页习题4.5：技术路线与使用说明

## 目标与范围

基于 https://github.com/seanwu1105/neural-network-sandbox 的 Python 后端 / Qt 桥接 / QML 界面结构，新增三层前馈网络的批训练 BP 模块。原题提供的 `seanwul105` 地址返回404，实际下载的是 `seanwu1105` 的仓库。原项目 README 和 MIT LICENSE 保留在项目目录。

本次只完成4.5，未包含4.6的 A、I、O 字符分类。XOR是程序验证数据，不替代后续题目的实验数据。

## 第一步：确定算法约定

- 三层 = 输入层、一个隐含层、输出层；结构记为 n–h–l。
- 输入层不使用激活函数；隐含层与输出层统一采用所选 sigmoid。
- V 的形状为 (n+1,h)，W 的形状为 (h+1,l)。最后一行是偏置权值，常数输入为 +1；若教材使用阈值 θ，关系为 b=-θ。
- 所有权值与偏置用独立的 [-1,1] 均匀随机数初始化。
- 固定学习率，无动量，无自适应优化器，全体样本参与训练，不自动划分训练/测试集。
- 图4.6的 E_RME 没有给出定义，暂约定为 RMSE=sqrt(2E/(P*l))。若教材前文定义不同，应修改停止指标。

## 第二步：实现前向传播和两种激活函数

对整批样本矩阵 X，增加一列常数1，记为 Xb：

H=f(Xb V)，Hb=[H,1]，O=f(Hb W)。

单极性 f(z)=1/(1+exp(-z))，导数为 y(1-y)。

双极性 f(z)=2/(1+exp(-z))-1，导数为 (1-y²)/2。

双极性采用的是 logistic 的双极性形式，等于 tanh(z/2)，不直接使用 tanh(z)。数值实现采用稳定 logistic，防止指数溢出。

## 第三步：实现整批 BP

误差 E=1/2 * sum((D-O)²)，对全部样本和全部输出求和。

采用负梯度方向的误差信号：

δo=(O-D) ⊙ f'(O)

δh=(δo W_nonbias^T) ⊙ f'(H)

∇W=Hb^T δo，∇V=Xb^T δh。

V_new=V_old-η∇V，W_new=W_old-η∇W。

两组梯度必须先用旧权值全部算好，再更新。矩阵计算等价于逐样本累加梯度，因此每轮只有一次整批更新。

这里对应教材的总误差 E，梯度不除以样本数。数据集变大时可能需要减小学习率；如果以后改为平均误差梯度，须明确新的学习率含义。

## 第四步：接入界面和训练控制

新增模块位于 `neural-network-sandbox-master`：

| 文件 | 职责 |
|---|---|
| nn_sandbox/backend/algorithms/batch_bp.py | 参数验证、初始化、前向、梯度、整批训练 |
| nn_sandbox/bridges/batch_bp_bridge.py | 后台训练线程、进度信号、停止控制 |
| nn_sandbox/frontend/exercise45.qml | 中文参数、数据输入、误差曲线和预测结果 |
| exercise45.py | 独立打开习题4.5界面 |
| run_experiment.py | 命令行训练，导出误差、结果、权值 |
| test_batch_bp.py | 算法验证 |
| check_gui.py | QML和训练线程集成检查 |

采用独立入口以保留原项目示例；没有使用原来的单样本 MLP 训练循环。新增桥接层通过 Qt 信号在主线程更新界面，训练过程中可以停止，关闭程序会等待工作线程结束。

## 第五步：验收

算法测试包括：两种激活函数的数值梯度检查（含多个输出及偏置）、一轮整批更新检查、随机初始化复现、两种 XOR 收敛、错误数据拒绝、提前停止和最大轮数终止。

默认配置：2–4–1，η=0.8，种子42，阈值0.05，最大20000轮。

| 激活函数 | XOR编码 | 达标轮数 | 最终 RMSE |
|---|---|---:|---:|
| 单极性 | 输入及目标为0/1 | 1031 | 0.04997122 |
| 双极性 | 输入及目标为-1/1 | 169 | 0.04990009 |

两种实验使用不同编码，该表不能证明双极性函数普遍收敛更快。以上结果属于训练集拟合验证，不是泛化能力评估。随机种子改变后可能收敛到不同解，达到最大轮数会明确显示未达标。

## 运行方式

本机启动入口优先使用 `D:/program/anaconda/python.exe`（Python 3.13.9），PyCharm 的4.5项目也关联此解释器，新增“习题4.5”运行配置。已通过 Anaconda 下的算法与界面训练检查。若不存在 Anaconda，启动脚本再尝试应用附带的 Python。

项目目录内 `.deps` 的依赖用于 Python 3.12；运行时会检查 sip 扩展兼容性，避免在 Python 3.13 下加载这些依赖。Anaconda 运行时由程序自动补充其 Qt 动态库搜索路径，无需全局添加 Library/bin。

Qt 在中文目录下的插件与 QML 路径问题已经通过 `qt_runtime.py` 显式设置路径解决。新页面的误差曲线使用 QML Canvas，支持软件渲染。6项算法测试和界面集成检查均已通过；界面检查实际触发“开始训练”按钮，验证工作线程完成和结果显示，预览保存在 `results/interface.png`。

双击项目目录中的 `启动习题4.5.cmd`，或在 PowerShell 中运行 `启动习题4.5.ps1`。修改参数，选择激活函数，然后点击“载入 XOR 示例”，确保数据编码与函数匹配，再开始训练。切换激活函数不会自动覆盖用户粘贴的数据。

自定义数据无表头，每行先写 n 个输入，再写 l 个目标；逗号或空格分隔。例如 2输入、2输出：

```text
0,1,0,1
1,0,1,0
```

单极性目标须在[0,1]，双极性目标须在[-1,1]。输入维度由数据决定，不能只改变输入节点数而不调整数据列数。

在已安装 Python 和依赖的其他电脑，可在项目目录运行：

```powershell
python -m pip install -r requirements.txt
python exercise45.py
python run_experiment.py --activation unipolar
python run_experiment.py --activation bipolar
python run_experiment.py --data data.csv --inputs 2 --hidden 6 --outputs 2 --learning-rate 0.1
python -m unittest test_batch_bp -v
```

本机命令行可使用 `& 'D:\program\anaconda\python.exe'` 替换示例中的 `python`。首次在 PyCharm 中加载新解释器配置后，请重新打开4.5项目，并选择“习题4.5”运行配置。

`results` 中 CSV 包含每一轮的 epoch/error/rmse；JSON包含参数、终止原因和预测；NPZ包含含偏置的 V/W 权值。相同激活函数的命令行实验默认覆盖对应结果文件，可用 `--output` 指定新目录保留不同实验。
