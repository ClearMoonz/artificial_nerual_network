# 教材配套软件预览

本文记录早期原软件预览。双击 launch_original.cmd 打开第9章的两个原演示：最速下降与共轭梯度对比、牛顿法。正式版本已整合为中文面板，可从项目根目录“启动程序.cmd”或本目录launch.cmd打开，详细说明见项目根目录README.md。

运行时最初不自动播放，点击软件窗口中的等高线绘图区开始。聊天中的PNG预览没有交互功能。修改程序后需关闭旧窗口并重新启动，旧进程不会自动加载修复。

已修复第9章动画在Qt可缩放窗口中的刷新问题：使用整图重绘而非blit局部刷新，并忽略坐标轴外的点击。实际Qt视口点击验证通过，覆盖对比页面的上下图启动与重新选点、牛顿页面点击播放。

动画现已改为每步0.5秒，持续迭代直到梯度范数不超过1e-6（最多1000步），右侧显示步数、梯度范数和停止状态。牛顿法结合Hessian区分极小点、鞍点和其他驻点；数值失败或越界时报告原因。到达极小点前的位置变化可能小于屏幕像素，此时应查看右侧步数和梯度范数。实际点击验证还覆盖最速下降持续收敛、共轭梯度两步停止、牛顿极小点/鞍点分类及初始点零梯度。

本机启动入口使用 D:/program/anaconda/python.exe（Python 3.13.9），双击入口使用同目录的 pythonw.exe。PyCharm已增加“梯度下降可视化”运行配置，VS Code已设置默认解释器。Qt依赖放在本项目内的anaconda_runtime，NumPy、SciPy与Matplotlib使用Anaconda已有版本，教材软件放在deps。此启动路径为本机配置，移到其他电脑需调整。

此前预览使用的Python 3.12依赖runtime保留；程序根据Python版本选择兼容的依赖目录。Anaconda对应的PyQt6为6.9.1，Qt6为6.9.2，与本机Anaconda的Qt6版本保持一致。

软件来源：https://pypi.org/project/nndesigndemos/ ，版本1.3.0。原软件及许可文件保留在deps目录。

预览直接调用原软件算法和页面，增加了中文路径的Qt配置、显式字体加载、仅加载第9章的入口及截图功能。截图前刷新原软件牛顿法动画的轨迹图层，以避免其局部刷新导致轨迹缺失；未修改算法计算公式。原牛顿页面的英文说明误写为steepest descent，实际执行的是牛顿更新，后续中文版应更正。

results目录已保存comparison.gif、comparison.png与newton.png。对比实验起点为(0.8,-0.25)，共轭梯度实际两步到达(0,0)；牛顿演示起点为(1.5,0)，实际趋向(0.55358,-0.55358)。

以上为原软件预览记录。技术路线中规划的中文统一面板、函数值曲线、单步/暂停、同条件对比和CSV/JSON导出已在gradient_descent_visualizer完成，并通过教材数值和实际界面交互测试。
